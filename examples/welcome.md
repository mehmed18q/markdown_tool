# متنِ دو زبانه، خواندنِ بی‌دردسر

اینجا **خوانا** است؛ یک فضای آرام برای خواندن فایل‌های Markdown و HTML. فارسی و English را کنار هم بخوانید، بدون اینکه ترتیب جمله‌ها، پرانتزها و کدها مزاحم خواندن شوند.

> برای شروع، روی **Open file** کلیک کنید یا فایل خود را داخل پنجره بیندازید. همه‌چیز روی دستگاه شما می‌ماند.

## فارسی و انگلیسی، کنار هم

برای اجرای پروژه، ابتدا Python را نصب کنید و سپس دستور `pip install -r requirements.txt` را در Terminal اجرا کنید. نسخهٔ Python 3.10 یا بالاتر مناسب است.

Markdown یک روش ساده برای نوشتن مستندات است. حتی وقتی جمله با یک واژهٔ انگلیسی آغاز می‌شود، ادامهٔ فارسی آن باید راحت خوانده شود.

This paragraph is written in English. It keeps its own left-to-right direction, even when a Persian word like «خوانا» appears inside it.

نشانی `https://example.com/docs` و مسیر `src/components/Reader.tsx` هم مستقل از جهت جمله نمایش داده می‌شوند. مقدار `version = "2.0.1"` باید دقیقاً همان ترتیبی را داشته باشد که نوشته‌اید.

## کد، با همان ترتیب درست

کدها همیشه از چپ به راست نمایش داده می‌شوند. با دکمهٔ بالای هر قطعه، می‌توانید آن را کپی کنید.

```python
from pathlib import Path

def read_document(file_path: str) -> str:
    # خواندن فایل با پشتیبانی از فارسی
    document = Path(file_path)
    return document.read_text(encoding="utf-8")

print(read_document("یادداشت‌ها.md"))
```

## جزئیات کوچک، خواندن بهتر

- **جهت هوشمند:** هر پاراگراف، عنوان و خانهٔ جدول جداگانه بررسی می‌شود.
- **کنترل در دست شما:** از نوار بالا، جهت کل متن را تغییر دهید. دکمهٔ کنار هر بخش هم جهت همان بخش را عوض می‌کند.
- **مطالعهٔ راحت:** اندازهٔ قلم، فاصلهٔ خطوط و رنگ محیط را تنظیم کنید.
- **پیدا کردن سریع:** با کلیدهای `Ctrl + F` در متن جست‌وجو کنید.

| قابلیت | میان‌بر | توضیح |
| --- | --- | --- |
| باز کردن فایل | `Ctrl + O` | انتخاب از دستگاه |
| جست‌وجو | `Ctrl + F` | جست‌وجو در سند فعلی |
| حالت تمرکز | `Ctrl + Shift + F` | فضای بیشتر برای خواندن |
| تازه‌سازی فایل | `Ctrl + R` | خواندن دوباره از دیسک |

## آماده برای نوشته‌های شما

از فهرست سمت چپ بین بخش‌های سند جابه‌جا شوید. چند فایل را هم‌زمان باز کنید و از بخش **OPEN FILES** به هرکدام برگردید.

---

برای ساختن سند تازه، **New document** را انتخاب کنید. با **Edit & Preview** متن را در کنار پیش‌نمایش زنده ویرایش کنید. **Save** تغییرات را ذخیره می‌کند و **Save As…** برای ذخیره با نام یا مسیر جدید است.

میان‌برهای `Ctrl + N`، `Ctrl + S` و `Ctrl + Shift + S` به‌ترتیب برای ساختن، ذخیره و ذخیره با نام جدید هستند. هنگام بستن سندی با تغییرات ذخیره‌نشده، می‌توانید **Save**، **Discard** یا **Cancel** را انتخاب کنید.
